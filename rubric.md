# Grading Rubric — AI/ML/Cybersecurity Lab Activity

## Total: 100 Points

---

### 1. Correctness & Accuracy (40 points)
- **36–40 pts**: Solution is fully correct. All outputs, results, or findings are accurate and complete.
- **28–35 pts**: Solution is mostly correct with minor errors that don't significantly impact the result.
- **16–27 pts**: Solution is partially correct. Core logic works but contains notable mistakes.
- **1–15 pts**: Significant errors. The approach is flawed or yields incorrect results.
- **0 pts**: No working solution submitted, or outputs are entirely wrong.

### 2. Code Quality & Best Practices (30 points)
- **27–30 pts**: Code is clean, well-organized, and follows Python best practices (PEP 8). Appropriate use of functions, classes, and libraries.
- **21–26 pts**: Code is readable and mostly follows conventions with minor style issues.
- **11–20 pts**: Code is functional but poorly organized, uses inefficient patterns, or has readability issues.
- **1–10 pts**: Code is messy, hard to follow, or relies on anti-patterns.
- **0 pts**: No code submitted or code does not run.

### 3. Algorithm & Logic Design (20 points)
- **18–20 pts**: Demonstrates a clear, efficient algorithmic approach. Justifies design choices. Handles edge cases.
- **14–17 pts**: Logic is sound but could be more efficient or handle edge cases better.
- **7–13 pts**: Basic logic is present but approach is naive or incomplete.
- **1–6 pts**: Limited evidence of intentional algorithmic thinking.
- **0 pts**: No logical approach discernible.

### 4. Documentation & Comments (10 points)
- **9–10 pts**: Code is thoroughly documented. Docstrings for all functions. Inline comments explain non-obvious logic.
- **7–8 pts**: Most code is documented. Key sections have comments.
- **4–6 pts**: Sparse documentation. Only some sections commented.
- **1–3 pts**: Minimal or no comments.
- **0 pts**: No documentation whatsoever.

---

## Special Penalties
- **Plagiarism / Copied Code**: Score of 0. Flag for academic integrity review.
- **Off-topic submission** (unrelated to the assignment): Score of 0.
- **Empty or placeholder submission**: Score of 0.
